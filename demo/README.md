# 固定演示案例

所有片段由本地 FFmpeg 生成，不包含外部下载视频、个人资料或相机拍摄数据。几何图形只是叙事分镜卡，视觉内容的中文描述属于固定标注。该模式验证流程，不评价真实模型效果。

首页“体验演示项目”创建 `missing`：窗边场景 + 完成结果，缺少制作过程。

|场景|输入与期望|
|---|---|
|complete|场景、过程、结果齐全；没有必要缺口|
|missing|移除过程；待确认的制作过程缺口|
|obscured|过程夹具标记遮挡；指出表达不足|
|unordered|结果、过程、场景；优先提出重剪|
|montage|氛围目标；不强加制作过程|
|dialogue|演示对白已交代场景；不误报纯视觉背景缺失|
|conflict|前后杯子属性冲突标注；输出连续性复核|
|partial|模拟过程分析失败；覆盖不完整，不断言全片不存在|

当前产品演示以单条 Vlog 为入口：

1. 上传已剪好的 Vlog，展示镜头切分与原片定位。
2. 完成分析，查看具体证据、补拍和重剪建议。
3. 确认建议后生成清单；重剪建议复制到外部剪辑软件中执行。
4. 上传补拍视频并分析是否满足要求；真实模型环境也支持 HappyHorse 生成候选镜头后分析、下载。
5. 查看“任务与消息”浮层中的处理进度；产品不提供剪辑、版本对比或成片导出。

上表是用于开发验证的历史固定夹具。此前的“试试无关镜头”“补入正确镜头”快捷按钮和粗剪导出演示步骤已经从产品移除。演示模式不会发起真实 AI 视频生成。

API 创建演示项目：`POST /api/v1/demo?scenario=missing`。仅当 `MODEL_PROVIDER=mock` 时允许，避免意外发送到真实模型服务。
